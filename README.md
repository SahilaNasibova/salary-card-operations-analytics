# Salary & Card Operations Analytics

**Oracle SQL | PL/SQL | Banking Data Analytics**

## Project Overview

This project focuses on salary card operations, salary-related banking transactions, and commission reporting using Oracle SQL and PL/SQL.

It includes database functions and procedures for retrieving salary card information, processing salary transactions, and calculating associated commissions.

## Key Components

### 1. Salary Card Analysis
- Retrieval of salary card information
- Card status and expiration date filtering
- Customer and branch-level data extraction
- Salary card product identification
- Report execution logging

### 2. Salary Operations & Commission Analysis
- Processing salary-related banking transactions
- Transaction filtering by branch and reporting period
- Identification of relevant corporate salary operations
- Commission amount calculations
- Intermediate data processing and reporting
- Error handling and execution logging

## Technical Skills

- Oracle SQL and PL/SQL
- Stored Functions and Procedures
- SYS_REFCURSOR
- Common Table Expressions (CTEs)
- INNER JOIN and LEFT JOIN
- EXISTS Subqueries
- CASE Expressions
- Aggregate Functions
- Data Filtering and Transformation
- Exception Handling
- Financial Reporting
